# Android GPS 기록 보조 앱

PC에서 사용자가 시작한 실제 GPS 이동 경로를 기록합니다. Android 8.0 이상이 필요합니다. 휴대폰에 설치된 뒤 PC의 기록 시작 요청을 받으면 보조 앱이 열립니다. 사용자가 휴대폰에서 **GPS 기록 시작**을 누르고 정확한 위치 권한(필요한 경우 알림 권한)을 허용해야 실제 기록이 시작됩니다. 기록 중 지속 알림을 표시하며, 알림의 **기록 중지** 또는 보조 앱에서도 PC 없이 중지할 수 있습니다.

기기의 GPS 제공자가 새로 전달한 위치만 수집합니다. 모의 위치, 이전에 수신한 위치와 30초 이상 오래된 위치는 저장하지 않습니다. 신호가 없거나 약한 실내에서는 위치가 수신되지 않을 수 있습니다. 각 점은 기기의 측정 시각·위도·경도·정확도를 포함하며, 데이터는 앱의 개인 저장소에 보관됩니다. PC는 해당 앱의 디버그 빌드에 `adb run-as`로 접근해 사용자가 요청한 세션을 동기화합니다.

## 직접 빌드

Android SDK 플랫폼 35, 빌드 도구 35.0.0, JDK 및 `zip`이 필요합니다. `ANDROID_HOME` 또는 `ANDROID_SDK_ROOT`를 지정한 뒤 다음 명령을 실행합니다.

```sh
./gps_helper/build.sh
```

빌드 결과는 `gps_helper/gps-helper.apk`입니다. 빌드 스크립트는 `~/.android/debug.keystore`를 사용하며, 없을 때 생성합니다. **다른 서명으로 빌드된 앱은 기존 설치본 위에 업데이트할 수 없습니다.** 기록이 필요하다면 기존 앱 데이터를 먼저 PC로 동기화하세요. 보조 앱을 제거하거나 앱 데이터를 지우면 아직 동기화하지 않은 기록이 삭제됩니다.
